# Screen Inventory

## 1. Billing Screen (Default)
- **Purpose:** Core checkout loop.
- **Entry Points:** App launch, returning from History/Products.
- **Exit Points:** `F2` (History), `F3` (Products), `F9` (Settings).
- **Primary Action:** `F12` (Print).

## 2. History Screen
- **Purpose:** View past receipts and reprint.
- **Entry Points:** `F2` from Billing.
- **Exit Points:** `Esc` to return to Billing.
- **Primary Action:** `Enter` (View Details), `P` (Reprint).

## 3. Product Management Screen
- **Purpose:** Add/Edit inventory.
- **Entry Points:** `F3` from Billing.
- **Exit Points:** `Esc` to return to Billing.
- **Primary Action:** `Ctrl+N` (New), `Enter` (Save).

## 4. Settings Screen
- **Purpose:** Configure app.
- **Entry Points:** `F9` from Billing.
- **Exit Points:** `Esc` to return to Billing.
- **Primary Action:** Automatically saves on change.
