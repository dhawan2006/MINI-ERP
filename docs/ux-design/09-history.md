# Bill History UX

## History Screen Design
- **Entry:** Press `F2`.
- **Structure:** A simple chronological table of past bills. Default sorted by newest first.
- **Search:** A search bar at the top (auto-focused on entry) allows typing a Bill ID or Date.
- **Detail View:** Pressing `Enter` on a selected row expands it inline to show the items, or opens a side panel.
- **Actions:** 
  - `P`: Reprint selected bill.
  - `E`: Export as PDF.
- **Exit:** Press `Esc` to instantly return to the Billing Screen. The master input is immediately auto-focused.
