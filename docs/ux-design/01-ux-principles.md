# UX Principles

## UX North Star
**MAXIMUM BILLING THROUGHPUT WITH MINIMUM COGNITIVE LOAD AND MINIMUM USER INTERACTION.**

Every UX decision is evaluated against:
- **Speed:** Can this be done in <100ms?
- **Simplicity:** Does it avoid unnecessary visual elements?
- **Predictability:** Does the same action always yield the same result without edge-case dialogs?
- **Recoverability:** Can a mistake be fixed with a single keystroke?
- **Readability:** Is the text large and high-contrast enough to be read from an angle?
- **Keyboard/Barcode Efficiency:** Does this require the mouse? (If yes, it's rejected for checkout).
- **Visual Calmness:** Does the UI avoid blinking, shifting layouts, or intrusive animations?
