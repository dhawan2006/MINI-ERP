# Settings UX

## Settings Strategy
Settings are kept to an absolute minimum for V1. If a setting doesn't solve a recurring operational problem, it is excluded.

## Included Settings (V1)
1. **Printer Selection:** Dropdown of OS-recognized printers. Default: "Auto-detect Thermal".
2. **Audio Feedback:** Toggle (On/Off). Default: On.
3. **Shop Details:** Shop Name, Address, Phone Number (for the receipt header).

## Excluded Settings
- Visual themes (Light/Dark mode) - UI is forced to high-contrast Light mode for clarity under fluorescent shop lights.
- Tax configuration (V1 is non-accounting).
- Complex receipt formatting (V1 uses a hardcoded, highly optimized template).
