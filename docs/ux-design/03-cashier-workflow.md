# Cashier Workflow Experience

## Cashier's Point of View
- **What they see first:** A massive, empty input field ready for a scanner, a zeroed total, and an empty list.
- **Focus:** The master input field ALWAYS has focus.
- **Attention:** The cashier's eyes are mostly on the physical products, not the screen. They look at the screen only to verify the Grand Total or to recover from a "Buzz" error sound.
- **Hands:** One hand on the scanner, one hand near the Numpad/Function keys. The mouse is untouched.
- **Screen-Free Operation:** A perfect transaction requires 0 screen glances. (Scan -> Ding -> Scan -> Ding -> F12 -> Receipt prints).
- **Mistake Recovery:** Hear a double-ding? Press `Delete`.
- **Next Customer:** The moment the printer starts, the screen is already reset for Customer 2.
