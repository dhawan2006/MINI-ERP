# Keyboard Shortcuts

## Status
CONFIRMED (Stage 1)

## Core Shortcuts
- `F12` or `Ctrl+P`: Commit Bill & Print.
- `Enter` (when search is empty): Commit Bill (No Print).
- `F1` or `/`: Focus search/scan input manually (fallback for auto-focus).
- `F4` or `*`: Edit quantity of the currently selected/last added line item.
- `Delete` or `Ctrl+Backspace`: Remove selected line item instantly.
- `Esc`: Clear search input.
- `Esc` (Double-tap within 2s): Void/Clear the entire active bill.
- `F8`: Retry the most recently failed print job.
